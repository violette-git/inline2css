A plain HTML dashboard, moved out of its style attributes

This page has 11 inline styles and a small hand-written stylesheet with hover states, a media query and an animation. inline2css turns the 11 style attributes into 8 classes, because three paragraphs share one set of styles and two share another, so each set is written once.

The three naming modes give the same result with different class names. The resolved output goes one step further: it folds framework.css into the new file, keeps the hover, media query and animation rules, and leaves out the 4 rules nothing on the page uses.

One element, before and after

The style attribute is replaced by a class, and the class gets its own rule in the new stylesheet.

Before original.html

<p class="card-body" style="color:#4b5563; line-height:1.5;">Up and to the right, mostly.</p>

After output-basic.html

<p class="card-body i2c-3">Up and to the right, mostly.</p>

New rule output-basic.css

.i2c-3:not(#\#) {
    color: #4b5563;
    line-height: 1.5;
}

The same two declarations appear on three paragraphs, so they become a single class used three times. Here is that class under each naming mode:

output-basic.css.i2c-3
output-semantic.css.i2c-color-4b5563-fa62
output-hash.css.i2c-fa62b4

Commands

Run these from the repository root, after cd node && npm install, to regenerate each output.

  1. Default naming output-basic
    $ node node/bin/cli.js examples/01-plain-html/original.html --css examples/01-plain-html/output-basic.css --html-out examples/01-plain-html/output-basic.html
  2. Semantic names, minified output-semantic
    $ node node/bin/cli.js examples/01-plain-html/original.html --naming semantic --minify --css examples/01-plain-html/output-semantic.css --html-out examples/01-plain-html/output-semantic.html
  3. Hashed names output-hash
    $ node node/bin/cli.js examples/01-plain-html/original.html --naming hash --css examples/01-plain-html/output-hash.css --html-out examples/01-plain-html/output-hash.html
  4. Resolved output-resolved
    $ node node/bin/cli.js examples/01-plain-html/original.html --resolve-linked --css examples/01-plain-html/output-resolved.css --html-out examples/01-plain-html/output-resolved.html
