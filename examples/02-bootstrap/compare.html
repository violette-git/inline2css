A Bootstrap page, including the inline style Bootstrap fights

This is a real Bootstrap 5.3 page with 6 inline styles. The interesting one is on the Pricing link. Bootstrap pads nav links with a three-class selector, .navbar-expand-lg .navbar-nav .nav-link, which beats an ordinary one-class rule. A careless conversion would lose that padding.

inline2css writes every extracted rule as .i2c-1:not(#\#). The :not(#\#) part adds the weight of an ID without matching anything extra, so the new class wins over Bootstrap the same way the inline style did. The resolved outputs also fold Bootstrap in, keep the 194 rules this page can use and drop the other 2,356, so the page loads about 37 KB of CSS instead of 232 KB.

One element, before and after

The style attribute is replaced by a class, and the class gets its own rule in the new stylesheet.

Before original.html

<a class="nav-link" href="#" style="padding:0 40px;color:crimson">Pricing</a>

After output-basic.html

<a class="nav-link i2c-1" href="#">Pricing</a>

New rule output-basic.css

.i2c-1:not(#\#) {
    padding: 0 40px;
    color: crimson;
}

Bootstrap's rule for this link has three classes. A plain .i2c-1 has one, so it would lose and the link would get Bootstrap's padding back. With :not(#\#) the rule counts as one ID plus one class, which outranks any number of classes, so the 40 px padding and crimson color survive. It still loses to !important, just as an inline style does.

Commands

Run these from the repository root, after cd node && npm install, to regenerate each output.

  1. Inline styles only output-basic
    $ node node/bin/cli.js examples/02-bootstrap/original.html --css examples/02-bootstrap/output-basic.css --html-out examples/02-bootstrap/output-basic.html
  2. Resolved output-resolved
    $ node node/bin/cli.js examples/02-bootstrap/original.html --resolve-linked --css examples/02-bootstrap/output-resolved.css --html-out examples/02-bootstrap/output-resolved.html
  3. Resolved and minified output-resolved-minified
    $ node node/bin/cli.js examples/02-bootstrap/original.html --resolve-linked --minify --css examples/02-bootstrap/output-resolved-minified.css --html-out examples/02-bootstrap/output-resolved-minified.html
