A Tailwind page with responsive, state and arbitrary classes

This is a real compiled Tailwind 4.3 page. It uses responsive (md:, sm:), hover, focus, disabled and arbitrary-value (w-[137px]) classes, plus 3 inline styles.

Tailwind already ships only the classes a page uses, so resolving it drops nothing: all 112 rules are kept, cascade layers included. The resolved file is a little larger than tailwind.css because it is written out readably (add --minify for a smaller file), and the page loads one stylesheet instead of two.

One element, before and after

The style attribute is replaced by a class, and the class gets its own rule in the new stylesheet.

Before original.html

<h1 class="text-3xl font-bold tracking-tight" style="color:#312e81">Dashboard</h1>

After output-basic.html

<h1 class="text-3xl font-bold tracking-tight i2c-1">Dashboard</h1>

New rule output-basic.css

.i2c-1:not(#\#) {
    color: #312e81;
}

The Tailwind classes are left alone and the inline color becomes one more class next to them. Tailwind puts its utilities in a cascade layer, and unlayered rules like this one beat layered ones, so the heading keeps its color.

Commands

Run these from the repository root, after cd node && npm install, to regenerate each output.

  1. Inline styles only output-basic
    $ node node/bin/cli.js examples/03-tailwind/original.html --css examples/03-tailwind/output-basic.css --html-out examples/03-tailwind/output-basic.html
  2. Resolved output-resolved
    $ node node/bin/cli.js examples/03-tailwind/original.html --resolve-linked --css examples/03-tailwind/output-resolved.css --html-out examples/03-tailwind/output-resolved.html
